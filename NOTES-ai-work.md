# AI work log

Written while building, not afterwards. One entry per meaningful step.

Three questions each time:
1. What did I hand to Claude Code — and why that part rather than another?
2. What came back that was wrong, fragile, or more complicated than it needed to be? Be specific:
   which function, which line, what actually broke.
3. How did I notice, and what did I change?

Target: at least three entries where the AI was wrong. They will happen. Selectors that only work on
one fixture, a prompt that collapses on short text, JSON returned without schema validation.
